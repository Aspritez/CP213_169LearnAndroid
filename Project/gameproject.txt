Project : "focusshot" เป็น game application ในโทรศัพท์ที่ทำโดยตัวเกมนี้จะคล้ายๆ กับตัวของ gridshot ใน aimlabเพราะเกิดจากว่าเล่นแล้วรู้สึกเราสามารถจดจ่อกับมันได้นาน จึงอยากทำออกมาเป็นแอพในโทรศัพท์เพื่อเป้นการฝึกสมาธิให้กับตัวเอง
Gameplay : เป้าหมาย (Circles) จะปรากฏขึ้นบนหน้าจอแบบสุ่มตำแหน่งในขอบเขตที่กำหนด ขอบเขตที่กำหนดจะเป้นในรุปแบบของตารางเป็น 3x3, ผู้ใช้ต้องแตะเป้าหมายให้หายไป เพื่อให้เป้าหมายใหม่ปรากฏขึ้นมาแทนที่ทันทีพร้อมการจับเวลา (1 นาที) 
- ต้องการที่จะพัฒนา game นี้ด้วยโครงสร้าง MVI
-โดยตัวเกมจะใช้ UI ที่สะอาดตาเพื่อให้ผู้ใช้สามารถโฟกัสได้เต็มที่ พร้อมกับมีเสียงเอฟเฟกต์เบาๆ ตอนกดที่เป้าหมาย 
- เราสามารถที่ปรับแต่งตัวเกมผ่าน setting 
setting 
- สามารถที่จะแก้ไข เปิด/ปิดเพลง, เปิด/ปิดเสียงเอฟเฟกต์, เปลี่ยนรูปเป้าหมายได้ ปรับสีเป้าหมายได้
