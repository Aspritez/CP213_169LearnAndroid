แอปที่ต้องการทำ : "FocusShot" game application ที่ได้รับแรงบรรดาลใจจาก gridshot ใน Aimlab โดยตัวเกมนี้เราจะเปลี่ยนเป้าหมายจากการฝึกความแม่นยำ มาเป็นการฝึกสมาธิและการจดจ่อผ่านการตอบสนอง 
mvp : มีหน้าเล่นเกมที่สามารถเล่นเกมได้จริง มีระบบการนับคะแนนตามความแม่นยำของผู้ใช้ ผุ้เล่นสามารถเล่นเกมได้โดยไม่ติดขัด
feature : 	
	Gameplay : เป้าหมาย (Circles) จะปรากฏขึ้นบนหน้าจอแบบสุ่มตำแหน่งในขอบเขตที่กำหนด, ผู้ใช้ต้องแตะเป้าหมายให้หายไป เพื่อให้เป้าหมายใหม่ปรากฏขึ้นมาแทนที่ทันทีพร้อมกำหนดเวลาต่อรอบ
	- ใช้ UI ที่สะอาดตา (Clean UI) ลดสิ่งรบกวนสายตา
	- มีเอฟเฟกต์ภาพหรือเสียงเบาๆ เมื่อแตะโดนเป้าหมาย
